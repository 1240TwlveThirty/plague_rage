# Задача 21: правило кеглей пиксельного шрифта

Новое правило: кегль = родной × k. По умолчанию k ≥ 2, то есть не мельче двойного родного. Из допустимых берётся
ближайший к заданному, при равной разнице — больший. Вариант по умолчанию по-прежнему `default`, его вид не изменился.
Снимки — `bench/report_21/index.md`. Симуляция не изменилась: регрессия против эталона и regress_hero — бит в бит.

## Этап A: правило

- **`data/ui_theme.json`, раздел `fonts`:**
  - `"min_scale": 2` — наименьший множитель родного кегля;
  - `"rounding": "nearest"` — ближайший, при равной разнице больший. Второй вариант — `"down"`: вниз, как в задаче 20.

  Оба ключа можно переопределить у отдельного варианта в `fonts.variants`. Вариант default размеры не меняет.
- **`scripts/fonts.gd`:** `px(size) = native × max(min_scale, floor(size / native + 0.5))`, для `down` — `floor(size / native)`.
  Подгонка текста кнопок (`fit_sizes`) перебирает только допустимые кегли. С min_scale 2 для кнопок магазина и отрядов
  остаётся один кегль: 24 в fusion12, 20 в fusion10.
- **Тест `check_v70_fonts`** проверяет правило по данным (`min_scale`, `rounding` читаются из `ui_theme.json`): кегль
  допустимый и ближе всех к заданному, при равенстве больший. Кегли собираются из кода, в тесте они не зашиты.

## Этап B: тексты

Знак «−» (U+2212) был не только у «Тяжёлых щитов», а в 11 описаниях карточек, в ru и en (22 вхождения).
Тест покрытия «без пропусков» проходит, только если заменить все, поэтому заменил везде на дефис «-», как в остальных описаниях:
- HEAVY_SHIELDS, LIGHT_INFANTRY, LONG_SHOT, QUICK_RELOAD, BLOOD_HARVEST, HUNGER_RATION;
- HEAVY_BAGGAGE, IRON_WALL, SHIELD_COVER, RICH_VEIN, LAST_BASTION.

`check_v51` ждал «Издержка: −10% к скорости» — поправлен на дефис.

Узкий неразрывный пробел U+202F убран из обязательного набора проверки: в игре его нет, и в Fusion Pixel его тоже нет.
В тексты его не добавлять, вместо него — U+00A0 (он в шрифте есть). Теперь `check_font_coverage` падает на любом
отсутствующем символе: 169 символов, 0 пропусков в обоих вариантах.
